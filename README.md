# Scorary

История просмотренного, прочитанного, пройденного и прослушанного.
Доступны игры, фильмы, сериалы, аниме, музыка, комиксы и манга. Состав разделов выбирается в настройках.

Этот репозиторий содержит готовые установщики, подписанные описания выпусков
и заметки об изменениях. Исходники разрабатываются в отдельном закрытом репозитории.
Личная коллекция пользователя не входит в установщик и не загружается сюда.

## Установка и обновление

Откройте [последний выпуск](https://github.com/CrabcoreMaster/scorary-releases/releases/latest).
Для первой установки на Mac с Apple Silicon используйте `.dmg` и перенесите
Scorary в папку «Программы». Для обновления установленной версии откройте
**Настройки → О приложении → Проверить**, затем **«Обновить и перезапустить»**.
Git и аккаунт GitHub для скачивания не требуются.

Начиная с 0.14.0 в настройках доступны только обычные обновления Scorary.
Выбор тестовых веток убран. Ранее созданные тестовые коллекции сохраняются
отдельно и не заменяют вашу основную библиотеку.

Приложение проверяет подпись Ed25519, размер и SHA-512 архива. Перед установкой
создаётся резервная копия библиотеки; при неудачном запуске возвращается прежняя
версия программы. Библиотека хранится отдельно от приложения на устройстве.

Текущие сборки Mac подписаны локально ad hoc, без Apple Developer ID/notarization.
Публичное распространение для широкого круга пользователей ещё не подготовлено.
Windows- и iPhone-версии Scorary пока не публикуются.
